Application Configuration & Admin Responsibilities

Revision 11 uses Firebase Authentication for credentials and Google Sheets / Apps Script for portal data, roles, leads and reporting. Firestore is not required.

Telecaller & Connector management

Approve pending signups, activate/deactivate accounts, assign Executive IDs, provision individual reporting Sheets and allocate/reassign leads.

Lead operations

Review website and executive leads, allocate unassigned enquiries, monitor stage/status/follow-ups and ensure executives receive only their created/assigned records.

Rates & lender content

Maintain the Loan Rates Google Sheet, verify lender ranges/fees/benchmarks, and control Telecaller/Connector visibility.

Schemes & subsidies

Maintain scheme content and decide whether Public, Telecaller and Connector roles can view the Schemes page.

Authentication

Firebase Email/Password Authentication stores passwords. The Executive Users Sheet stores UID, username, role, status and audit fields—but never the password.

Profile photos

Profile photos are uploaded through Apps Script into the Google Drive folder HelloCustomer Executive Profile Photos; only the file ID/URL is stored in the user record.

Individual reporting

Approval creates a separate Google Spreadsheet for the executive. Created/assigned CRM leads are synchronised into that person's My Leads tab.

Security & exits

Deactivate users immediately when access should stop. Firebase ID tokens are verified by the Apps Script backend before protected CRM operations.

Production prerequisites: Firebase Email/Password enabled; Google Sheet bound to the latest google-apps-script.gs; setup() run once; Web App deployed as Execute as Me / Anyone; first Admin record created with setupAdminUser(...); GitHub Pages deployed with the same Apps Script URL.
